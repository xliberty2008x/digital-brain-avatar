# Contributing

External contributors open a **fork** PR into `master`.

## Merge gates

Before merge, every PR must have:

1. **python** CI (quality workflow) green
2. **GitGuardian** checks green
3. **Central Grok review** completed
4. **All review discussions resolved**
5. **Owner review** approval (`@xliberty2008x`)

Do not open PRs from same-repo branches for external contributions; use a fork.
